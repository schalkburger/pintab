Instructions

Automatically pin tabs by defining rules based on their URL. If you're unfamiliar with regular expressions, you can simply use the full URL you want to pin.

To toggle the pinned state of the current tab, you can set a keyboard shortcut. Go to the Chrome Extension Shortcuts page and assign a command (e.g., Alt+P).

To match both http and https, use http[s]? or ^http[s]{0,1}://www.facebook.com/$.

URL Pinning Rules

Each rule has two main parts: a Rule Name for identification and a Regular Expression to match a URL.

The optional Tab Position field specifies the tab's location from the left (e.g., '0' is the first tab, '2' is the third). If left empty, it defaults to the end.

Checking the Disable box will deactivate the rule. Note that a URL could still be pinned if it matches another active rule.
