PinTab Options

Instructions

Automatically pin tabs using URL-based rules.

If you're unfamiliar with regular expressions, just use the full URL you want to pin.

A common regex pattern that you can use is e.g. ^https?://gemini\.google\.com/

This pattern matches all Gemini chat pages, not just the homepage.

URL Pinning Rules

  • Each rule has two main parts: a Rule Name for identification and a Regular Expression to match a URL.
  • The optional Tab Position field specifies the tab's location from the left (e.g., '0' is the first tab, '2' is the third).
    If left empty, it defaults to the end.
  • Checking the Disable box will deactivate the rule. Note that a URL could still be pinned if it matches another active rule.
